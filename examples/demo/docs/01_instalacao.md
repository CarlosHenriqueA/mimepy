# Instalação — Solaris Kit (fictício)

Para fins de demonstração, o "Solaris Kit" se instala em segundos.

## Requisitos

| Recurso | Mínimo |
|---|---|
| Runtime | Qualquer dispositivo com navegador |
| Dependências | Nenhuma (HTML autocontido) |
| Conexão | Não é necessária (offline) |

## Passo a passo

1. Baixe o pacote (fictício) do repositório.
2. Copie os componentes para o seu projeto.
3. Importe o CSS e comece a usar.

```html
<link rel="stylesheet" href="solaris.css">
```

> **Nota:** tudo neste exemplo é **fictício** — o objetivo é demonstrar o
> framework MimePy em ação, não um produto real.
