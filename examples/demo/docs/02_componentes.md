# Componentes — Solaris Kit (fictício)

O kit (fictício) oferece alguns componentes básicos.

## Componentes disponíveis

| Componente | Descrição |
|---|---|
| `Botão` | Criar botões acessíveis |
| `Card` | Cartões com estrutura consistente |
| `Tabela` | Tabelas responsivas |
| `Nota` | Caixas de destaque |

## Exemplo de componente

### 🔘 Botão

```html
<button class="sk-btn">Ação</button>
```

### ▢ Card

```html
<div class="sk-card">
  <h3>Título</h3>
  <p>Conteúdo do card.</p>
</div>
```

> Estes são exemplos **fictícios** para demonstração.
