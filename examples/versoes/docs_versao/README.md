# Meu Produto — Visão geral

O **Meu Produto** resolve um problema real de forma simples. Esta documentação
é gerada com o **MimePy** a partir de Markdown puro e existe em **múltiplas
versões** (`/v1/`, `/v2/`...) — veja como no `examples/versoes/`.

| Versão | Status | Pasta de saída |
|---|---|---|
| v1 | estável | `out_v1/` |
| v2 | em desenvolvimento | `out_v2/` |

> **Só Markdown:** as duas versões usam **os mesmos arquivos `.md`** — o que
> muda é só o `config.py` (`page_title`, `out_dir`). Zero dependência nova.
