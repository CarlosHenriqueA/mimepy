# Instalação

Para instalar o **[projeto]** basta uma única dependência:

```bash
pip install markdown
```

## Requisitos

- Python 3.9+
- Nenhuma outra dependência além do `markdown`

## Verificando a instalação

```bash
python -c "import markdown; print(markdown.__version__)"
```

> Instalação é o único passo necessário — o resto é configurar e gerar.
